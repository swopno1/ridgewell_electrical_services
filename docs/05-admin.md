# Administrator Console

The **Admin Console** provides tools for managing the workforce, project portfolio, and financial reporting. All features in this section require the **ADMIN** role.

---

## 1. Employee Directory Management

### Registering New Employees

1. Navigate to **Employees** → **Add Employee**.
2. Fill in: **Full Name**, **Email Address**, and **Role** (Employee, Manager, or Admin).
3. Click **Create Employee**.

**What happens automatically:**
- A leave balance of **20 days** is created for the current year.
- The account is created in an **inactive** state — you must activate it before the employee can sign in.
- A system-generated temporary password is assigned. The employee must change it on first sign-in via **Settings**.

### Activating an Account

New accounts default to **inactive**. To allow sign-in:

1. Locate the employee in the directory.
2. Toggle the **Active** switch to enabled.

### Modifying Employee Details

1. Locate the employee and click **Edit** (pencil icon).
2. Update name, email, role, hourly rate, or leave entitlement.
3. Click **Save Changes**.

---

## 2. Account Deactivation

Setting an account to **Inactive** immediately:

- Blocks the user from signing in.
- Invalidates all active sessions.
- Prevents new timesheets or leave requests from being submitted.

Historical data (timesheets, leave records, approvals) is **fully preserved** and remains accessible in reports.

---

## 3. Project Administration

### Creating New Projects

1. Navigate to **Projects** → **Create Project**.
2. Enter **Project Name**, **Client Name**, and an optional **Description**.
3. Set the initial status to **Active** or **Inactive**.

### Managing Project Status

| Status | Effect |
| :--- | :--- |
| **Active** | Visible in the project dropdown when logging timesheets |
| **Inactive** | Hidden from new entries; retained in historical reports |

---

## 4. Reports & Exports

### Generating Summaries

1. Navigate to **Reports** in the sidebar.
2. Select a report type: **Hours Summary**, **Payroll Summary**, or **Project Report**.
3. Use the **Date Range Picker** to filter results.

### Exporting Data

From any report view, click **Export** and choose:

- **CSV** — for Excel, payroll software, or further analysis.
- **PDF** — for archiving or sharing.

---

## 5. System Settings

The **Settings** page allows Admins to configure application-level options. Changes take effect immediately and apply to all users.
